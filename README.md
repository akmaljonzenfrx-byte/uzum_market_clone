# Uzum Market - Onlayn Do'kon va Tezkor Yetkazib Berish Platfo

Uzum Market uslubidagi zamonaviy, tezkor va qulay e-commerce platformasi veb-sayti. Unda mahsulotlar katalogi, qidiruv, savat, bo'lib to'lash kalkulyatori va aksiya taymeri joy olgan.

## Ishga tushirish

Loyiha bir faylli self-contained SPA (Single Page Application) sifatida yaratilgan. Hech qanday qo'shimcha freymvork yoki server talab etilmaydi, brauzerda to'g'ridan-to mezoniy ishlaydi.

`index.html faylini istalgan zamonaviy brauzerda oching`

_Jarvis tomonidan yaratildi._
